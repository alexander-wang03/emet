# The functions a merge gate or a floor rests on, for mutation testing (RP7).
#
# One `path::function` a line, a method as `path::Class.method`, the path
# from the repository's root; a line starting with `#` is a comment, and
# each group has one above it. `python tools/ci.py mutmut` reads this file
# and mutates the listed functions a branch changes, on Linux, in WSL or on
# the Pi (mutmut needs os.fork). A mutant no test kills is a change to a gate
# that no test would have caught.
#
# A helper a listed function calls in its own file is listed too, since a
# branch that changes only the helper would otherwise mutate nothing, or is
# named with its reason in LEFT_OUT in tools/tests/test_mutmut_targets.py,
# which holds the list to that rule.
#
# mutmut 3.8.1 makes no mutant of a decorated function (a property, a
# function under lru_cache), except one whose one decorator is staticmethod
# or classmethod (its mutation/file_mutation.py, read 2026-11-26), so no
# other decorated function is listed: a gate that rests on a property is
# tested directly. tools/tests/test_mutmut_targets.py holds every line to a
# function that exists and that mutmut mutates.
